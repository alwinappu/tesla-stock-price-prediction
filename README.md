# Tesla Stock Price Prediction 📈

This project predicts Tesla's stock closing price using Deep Learning time-series models.

## Models Used
- SimpleRNN
- LSTM

## Features
- Time-series forecasting (1, 5, 10 days)
- Model comparison using MSE
- Interactive Streamlit web application

## Tech Stack
- Python
- TensorFlow / Keras
- Pandas, NumPy, Scikit-learn
- Streamlit

## How to Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
